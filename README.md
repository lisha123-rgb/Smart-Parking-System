# Smart-Parking-System
# Smart Parking System for Smart Cities

A Smart and Sustainable Parking System developed using Python Flask, IoT concepts, OpenCV, HTML, CSS, JavaScript, and SQLite. The system helps users find parking slots efficiently, reduces traffic congestion, supports digital payments, and automates parking management.

## Features

* Real-time parking slot monitoring
* Automatic parking slot allocation
* Vehicle number plate detection
* Digital wallet/payment support
* Smart parking dashboard
* User login and booking system
* Parking history management
* Responsive frontend UI
* Automated entry and exit handling

## Installation

### Clone the Repository

```bash
git clone https://github.com/lisha123-rgb/Smart-Parking-System.git
```

### Move into the Project Folder

```bash
cd Smart-Parking-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Flask Application

```bash
python app.py
```

## Usage

1. Open the application in browser
2. Register/Login
3. Check available parking slots
4. Book a parking slot
5. Make payment through wallet
